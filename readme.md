C# is one of the dominant programing languages used in Software devolpment.The most used cases of C# is in the areas of Backend and cloud computing by ASP.NET Core and the first language of choice in Azure cloud although other cloud services supports .Net SDKs.
Although not as prevelant as python in the area of machine learning C# and by extention Dotnet offers library calle ML.net to build machine learning models train them and predict the outcomes. Apart from that .Net have other wrappers of Tensorflow, Numpy,Opencv etc for Deeplearning,Mathametical and Computer Vision operations etc. 
So if C# have a large number of libraies to implement machine learning algorithms why and what is the use of this new library and who names the library as ML.cs well to answer that ML.cs name is inspired by another popular library called d3.js(a javascript library for vizualization). ML.cs is a  small machine learning library writtern in C# in an attempt to devolp a ML library that is simple enough for beginners who have a basic understanding of C# and built ML models in python.
The library is havent yet reached the v1 stage but continously working on it. 
This library is pureley as an education purpose of how ML algorithms work under the hood and provide a learning experice. This is way of providing a simpler starting point for .Net devs who wanted to use ML in thier application.
